# Project Layout

This is a single-file web app. Keep the app entry point at `index.html` in the top level so GitHub Pages can serve it directly.

- `AGENTS.md`: project rules and layout guidance
- `spec.md`: project requirements and specifications
- `prompts.md`: record of requested tasks and outcomes
- `index.html`: the single-file web app
- `00_planning/`: planning notes and sketches
- `02_validation/`: hand calculations and test cases
- `03_output/`: screenshots and exported results

## File Placement Rule

Save new files in the folder that matches their purpose. Keep planning notes and sketches in `00_planning/`, hand calculations and test cases in `02_validation/`, and screenshots or exported results in `03_output/`. Keep project-level instructions and the web app's `index.html` at the top level.

After each request, add an entry to `prompts.md`: what I asked, what you changed, and whether it worked.
